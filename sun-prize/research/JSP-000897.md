## Proof accessibility

Strong. The 1983 Bondy note is only three journal pages (109–111). Its abstract gives a particularly clean strengthening: if a simple graph on `n` vertices has more than `t_r(n)` edges and `v` is any maximum-degree vertex of degree `m`, then the graph induced by the neighbors of `v` has more than `t_{r-1}(m)` edges. The official JSP wording is a neighborhood-density consequence at the corresponding Turán threshold.

## Likely proof structure

1. Fix a finite simple graph and a maximum-degree vertex.
2. Express the global edge hypothesis using the Turán number / canonical Turán graph.
3. Count edges between the neighbor set and its complement, using maximality of the chosen degree.
4. Assume the induced neighborhood is at or below the `(r-1)`-partite Turán bound.
5. Combine the counts to contradict the global `r`-partite Turán threshold.

The exact inequalities must be checked against Bondy's notation before proof coding.

## Formalization bottlenecks

- The paper uses the numeric function `t_r(n)` while Mathlib's core theorem is phrased structurally around `turanGraph` / maximal clique-free graphs; a clean bridge lemma is probably needed.
- Edge counts in `G.induce (neighborSet v)` must be transported cleanly to finite `neighborFinset` cardinalities.
- Integer rounding in balanced part sizes can create more Lean work than the graph argument itself.
