## 协作方式

ChatGPT 写研究规则/复核结果 → GitHub 保存可追踪版本 → 本地 Codex 拉取、开发、运行 → 提交允许公开的代码与脱敏摘要 → ChatGPT 在下一次实际调用 GitHub 时读取复核。

GitHub 同步的是已提交并推送的文件，不是聊天窗口的全部记忆；只在本地保存的文件不会自动出现在远端。STATUS.md 是交接入口，不是后台任务队列。

## 目录与原项目隔离

本轮只新增 `btc-research/` 下的规划文档，不修改仓库根目录的 README.md、index.html 或任何原项目文件。不扫描、不复制本地其他量化项目的核心代码与缓存。需要复用旧项目时，仅在用户明确指定范围后做本地只读审查，先评估通用组件，绝不直接迁移 A 股交易制度假设。

当前承载仓库为公开仓库。文档使用通用的 1000 USDT 模拟账本参数，不存储个人身份、真实资金状况、账户余额、钱包地址、密钥或个人电脑绝对路径。私有策略代码是否公开需要单独授权；不要因存在 Git 远端就自动推送任何本地内容。

## 什么才叫完成

第一版验收看：输入可追溯、时间无歧义、缺失显式报告、现金与持仓可逐笔核对、测试有真实输出、结果可复现。亏损的正确回测也可以通过工程验收；漂亮但不可复核的收益曲线不能通过。

M1 完成前，禁止宣称已经有交易优势、策略已经赚钱或实盘已就绪。当前没有完成任何下载、回测、收益统计或本地环境检查。
